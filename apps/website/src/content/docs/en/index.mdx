## Not a traditional component library

Verdigris breaks Minecraft's GUI language into copyable React source. It ships through two channels: an npm package and source directories. Components are built on Base UI and Tailwind CSS v4, driven by design tokens by default.

The 66 components cover four layers: 13 primitives, 12 containers, 9 HUD status layers and 32 full-screen interfaces. Full screens are not black boxes; they are compositions of smaller parts.

<Callout title="Three ground rules">
Source you can own: every component is its own directory. Data injection: screens receive data and callbacks only. Token overrides: colors, type, spacing and shadows can all be rewritten in `@theme`.
</Callout>

## Five design principles

1. Compose by layer, not as full-screen black boxes. Screens are built from `ScreenPanel`, `PlayerInventory`, `Slot` and friends.
2. Keep UI and game logic separate. Components read no saves and send no requests; they render the data passed in.
3. Style through tokens. Geometry and color come from CSS variables; override variables to reskin.
4. Stay pixel-first. 1 GUI px equals 2 CSS px by default; textures use `image-rendering: pixelated`.
5. Prefer static rendering. Presentational components stay RSC-compatible and interactive boundaries stay small.

## Distribution

`@verdigris/ui` is a workspace package. The repo also includes `registry/registry.json`, which describes component source and dependencies using the shadcn registry shape. The registry currently covers primitives and containers only.
