## Redraw strategy

GUI nine-slices and progress bars are redrawn for this project. Item, block and HUD status icons come from the official Minecraft Java 26.3 client (pinned version and SHA-1), generated as base64 PNG data URIs by `packages/textures/scripts/sync-vanilla-icons.mjs`. Block icons are composed as isometric cubes from three visible faces exactly like the vanilla item renderer (`rotateX 30° · rotateY 225° · scale 0.625`), with per-face brightness from `Direction.getShade()`: top 1.0 / north 0.8 / east 0.6. See `packages/textures/LICENSE-ASSETS.md`.

## Nine-slice

Buttons and panels use a 12×12 source with slice 3 through `border-image`. Border widths scale with `--mc-gui`, so changing GUI scale does not stretch or blur the art. Every texture class sets `image-rendering: pixelated`.

```css
.mc-tex-panel {
  border: calc(var(--mc-gui) * 3) solid transparent;
  border-image: url("/textures/panel.svg") 3 / calc(var(--mc-gui) * 3) stretch;
}
```

## Icons

<IconGrid />

```tsx
import { Icon } from "@tennantite/ui";

<Icon name="grass-block" size={16} />
```

`size` is in GUI px and defaults to 16. Icons are `aria-hidden` by default; provide an `aria-label` or nearby text when they carry meaning.

## Import

```css
@import "@tennantite/textures/css/textures.css";
```

<Callout>
Texture classes work on any element, but depend on the CSS variables from `@tennantite/textures`. If you copy a single icon, you do not need the full texture stylesheet.
</Callout>
