## 重绘策略

GUI 九宫格与进度条为本项目重绘；物品、方块与 HUD 状态图标取自 Minecraft Java 26.3 官方客户端（固定版本与 SHA-1），由 `packages/textures/scripts/sync-vanilla-icons.mjs` 生成 base64 PNG data URI。方块图标使用平面贴图，不是游戏内 3D 物品渲染。许可见 `packages/textures/LICENSE-ASSETS.md`。

## 九宫格

按钮与面板使用 12×12 源图、slice 3 的 `border-image`。边框宽度按 `--mc-gui` 缩放，因此 GUI scale 变化时纹理不会被拉伸模糊。所有纹理类内置 `image-rendering: pixelated`。

```css
.mc-tex-panel {
  border: calc(var(--mc-gui) * 3) solid transparent;
  border-image: url("/textures/panel.svg") 3 / calc(var(--mc-gui) * 3) stretch;
}
```

## 图标

<IconGrid />

```tsx
import { Icon } from "@tennantite/ui";

<Icon name="grass-block" size={16} />
```

`size` 的单位是 GUI px，默认 16。图标默认 `aria-hidden`；需要语义时由调用方提供 `aria-label` 或可见文本。

## 引入

```css
@import "@tennantite/textures/css/textures.css";
```

<Callout>
纹理类可以用于任意元素，但类名依赖 `@tennantite/textures` 的 CSS 变量。若只复制单个图标，不需要引入整份纹理样式。
</Callout>
